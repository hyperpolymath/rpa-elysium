== Overview

This guide covers packaging, deploying, and maintaining rpa-elysium for
distribution on your platform.

{{DEPS}}

== Build from Source

[source,bash]
----
git clone https://github.com/hyperpolymath/rpa-elysium.git
cd rpa-elysium
just build-release
----

Output: `{{BUILD_OUTPUT_PATH}}`

== Packaging

=== Guix

[source,bash]
----
guix build -f guix.scm
----

=== Nix

[source,bash]
----
nix build
----

=== Container (Stapeln)

[source,bash]
----
just stapeln-export    # Generates Containerfile
podman build -t rpa-elysium .
----

=== Manual Package

[source,bash]
----
just install --prefix=/usr/local
----

Files installed:

[cols="1,2"]
|===
| Path | Contents

| `$PREFIX/bin/`
| Executables

| `$PREFIX/share/rpa-elysium/`
| Data files, assets

| `$PREFIX/share/doc/rpa-elysium/`
| Documentation

| `$PREFIX/share/applications/`
| .desktop file (Linux, if GUI)

| `$PREFIX/share/man/man1/`
| Man pages
|===

== Configuration

Default config location: `$XDG_CONFIG_HOME/rpa-elysium/config.toml`

Fallback: `$HOME/.config/rpa-elysium/config.toml`

== Health Checks

[source,bash]
----
just doctor            # Full diagnostic
just run --version   # Version check
just run --selftest  # Built-in self-test
----

== Updating

[source,bash]
----
git pull
just build-release
just install --prefix=/usr/local
----

Or via OPSM: `opsm update rpa-elysium`

== Multi-Instance Deployment

For deploying multiple instances (e.g., different users or tenants):

[source,bash]
----
just install --prefix=/opt/rpa-elysium-instance1 --config=/etc/rpa-elysium/instance1.toml
just install --prefix=/opt/rpa-elysium-instance2 --config=/etc/rpa-elysium/instance2.toml
----

Each instance has isolated config, data, and logs.
